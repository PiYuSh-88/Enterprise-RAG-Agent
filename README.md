# Enterprise RAG + Agent System

A production-oriented RAG and agent platform.

## Current Status

Project initialization.

## Goal

Build a deployable enterprise RAG system with:
- document ingestion
- retrieval
- grounded answers
- citations
- agentic tools
- enterprise access control
- evaluation and observability

See `roadmap.md` for the full phased specification and `NOTES.md` for locked-in
stack decisions.

## Development Rule

Implement the roadmap incrementally, one milestone at a time. No feature should
be added outside the current milestone without explicit approval.
